촬영 날짜·시간·장소를 수정하거나 삭제합니다. 사진은 서버로 전송되지 않습니다.

⚙ 설정

키는 이 기기의 브라우저에만 저장됩니다. 폰·PC 등 기기마다 한 번씩 입력해 주세요.

1사진 선택

기존 촬영시간 순서대로 정렬되며, 새 시간도 이 순서대로 부여됩니다.

2날짜·시간

부터
구간 안에서 사진마다 임의 시간(초 단위)이 부여됩니다. 날짜를 비우면 촬영일시가 삭제됩니다.

3장소

주소를 비우면 위치정보(GPS)가 삭제됩니다.
적용 규칙 · 날짜 입력 → 구간 내 랜덤 시간 부여 / 날짜 빈칸 → 시간 삭제
주소 입력 → 해당 위치로 변경 / 주소 빈칸 → 위치 삭제
